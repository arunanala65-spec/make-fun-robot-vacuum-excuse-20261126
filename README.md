A TypeScript program that writes the funniest one-line excuse a robot vacuum gives for missing a spot, told in the vacuum's own deadpan voice: its sensors find the crumb, its map files it as furniture, and its battery votes 1-0 to let it live — democracy is dusty. Every part of the joke lives in the vacuum's own world, and the punchline lands on the last three words.
